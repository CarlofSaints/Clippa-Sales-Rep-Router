# Guide screenshots

The guide at /guide expects the PNG files listed below. A slot with no file
renders as a labelled placeholder naming the shot, so a missing picture is
visible on the page rather than silently absent.

Drop a file in with the exact name and it appears. Nothing else to change.

| File | What to capture |
|---|---|
| `channels-grid.png` | Control Centre > Channels, full page, showing the grid and the Apply defaults button |
| `reps-import.png` | Reps page after choosing a file: the preview panel showing created, updated and unchanged counts |
| `store-upload.png` | Control Centre > Store Upload, showing the file chooser and the notes about column names |
| `coverage.png` | Control Centre > Store Coverage, showing the stat cards and the table of missing rep codes |
| `data-health.png` | Control Centre > Data Health, with one issue expanded to show its rows |
| `rep-account.png` | The /account page signed in as a rep, showing the "Where your day starts" card |
| `routes-generate.png` | Routes page showing the call cycle type selector and the Generate Routes button |
| `capacity.png` | Rep Capacity page showing the table of reps with utilisation percentages |
| `map.png` | Map page with a rep selected, showing numbered stops and the route line |

Roughly 1400px wide is plenty. The page scales them to its own width.

Anonymise anything that should not leave the client: real rep names and store
names are fine here since this guide is for Clippa themselves.
